CI/CD demo

A small web application built to demonstrate how automated testing and delivery can help teams release code more reliably.

View workflow runs

How the pipeline works

From a code change to a verified build.

01

Code

Changes are tracked and shared using Git and GitHub.

02

Test

Automated checks help catch errors before delivery.

03

Build

The application is packaged into a Docker image.

04

Verify

Workflow checks verify that the build and application respond as expected.

Note: the exact deployment steps depend on the GitHub Actions workflow configured in this repository.

Tools used

The project brings together tools for source control, testing, packaging, and security checks.

  • Git and GitHub
  • Node.js and Express
  • GitHub Actions
  • Jest and Supertest
  • ESLint and npm audit
  • Docker and Trivy
  • GitHub Container Registry

Application endpoints

The Express application exposes these routes for basic checks and app information.
